== 传疑时代（无确切纪年）

=== 五帝

依据：《史记·五帝本纪》

==== 黄帝（公孙轩辕）

姓公孙，名轩辕，少典之子。

* 神农氏世衰，诸侯相侵伐
* 轩辕习用干戈，以征不享
* 阪泉之战：与炎帝战于阪泉之野，三战，得志
* 涿鹿之战：蚩尤作乱，黄帝征师诸侯，战于涿鹿之野，禽杀蚩尤
* 诸侯尊轩辕为天子，代神农氏，是为黄帝
* 迁徙往来无常处，以师兵为营卫
* 举风后、力牧、常先、大鸿以治民
* 官名皆以云命，为云师
* 置左右大监，监于万国
* 获宝鼎，迎日推筴（cè，蓍草，用于占卜）
* 顺天地之纪，幽明之占，死生之说，存亡之难
* 时播百谷草木，淳化鸟兽虫蛾
* 旁罗日月星辰水波土石金玉，劳勤心力耳目，节用水火材物
* 东至于海，登丸山及岱宗；西至于空桐，登鸡头
* 南至于江，登熊湘；北逐荤粥（xūn yù，匈奴），合符釜山
* 娶西陵之女嫘祖为正妃，生二子：玄嚣（青阳）、昌意
* 黄帝崩，葬桥山

.原文
[quote]
____
黄帝者，少典之子，姓公孙，名曰轩辕。生而神灵，弱而能言，幼而徇
（xùn，敏捷）齐，长而敦敏，成而聪明。
____

[quote]
____
轩辕之时，神农氏世衰。诸侯相侵伐，暴虐百姓，而神农氏弗能征。於是
轩辕乃习用干戈，以征不享（不来朝贡者），诸侯咸来宾从。而蚩尤最为暴，
莫能伐。炎帝欲侵陵诸侯，诸侯咸归轩辕。轩辕乃修德振兵，治五气
（五行之气），蓺（yì，种植）五种（五谷），抚万民，度四方。
____

[quote]
____
教熊罴（pí）貔（pí）貅（xiū）貙（chū）虎，以与炎帝战於阪泉之野。
三战，然後得其志。蚩尤作乱，不用帝命。於是黄帝乃徵师诸侯，与蚩尤
战於涿鹿之野，遂禽杀蚩尤。而诸侯咸尊轩辕为天子，代神农氏，是为黄帝。
天下有不顺者，黄帝从而征之，平者去之，披山通道，未尝宁居。
____

==== 颛顼（zhuān xū／高阳）

黄帝之孙，昌意之子，名高阳。

* 静渊以有谋，疏通而知事
* 养材以任地，载时以象天
* 依鬼神以制义，治气以教化，絜诚以祭祀
* 北至于幽陵，南至于交趾，西至于流沙，东至于蟠木
* 动静之物，大小之神，日月所照，莫不砥属（顺服）
* 颛顼崩，玄嚣之孙高辛立

.原文
[quote]
____
帝颛顼高阳者，黄帝之孙而昌意之子也。静渊（沉静深远）以有谋，疏通
而知事；养材以任地，载时以象天，依鬼神以制义，治气以教化，絜
（jié，同"洁"）诚以祭祀。
____

[quote]
____
北至于幽陵，南至于交阯（zhǐ），西至于流沙，东至于蟠木。动静之物，
大小之神，日月所照，莫不砥（dǐ，平）属（归顺）。
____

==== 帝喾（kù／高辛氏）

黄帝之曾孙，高辛氏。高辛父曰蟜极，蟜极父曰玄嚣，玄嚣父曰黄帝。

* 生而神灵，自言其名
* 普施利物，不於其身
* 聪以知远，明以察微
* 顺天之义，知民之急
* 仁而威，惠而信，修身而天下服
* 取地之财而节用之，抚教万民而利诲之
* 历日月而迎送之，明鬼神而敬事之
* 日月所照，风雨所至，莫不从服
* 娶陈锋氏女，生放勋（尧）
* 娶娵訾氏女，生挚
* 帝喾崩，挚代立；帝挚不善，弟放勋立

.原文
[quote]
____
帝喾高辛者，黄帝之曾孙也。高辛父曰蟜（jiǎo）极，蟜极父曰玄嚣，
玄嚣父曰黄帝。自玄嚣与蟜极皆不得在位，至高辛即帝位。高辛於颛顼
为族子。高辛生而神灵，自言其名。普施利物，不於其身。聪以知远，
明以察微。顺天之义，知民之急。仁而威，惠而信，修身而天下服。
____

[quote]
____
取地之财而节用之，抚教万民而利诲（huì，教导）之，历日月而迎送之，
明鬼神而敬事之。其色郁郁（深沉），其德嶷嶷（yí，庄重）。其动也时，
其服也士（适当）。帝喾溉（gài，普及）执中而遍天下，日月所照，风雨
所至，莫不从服。
____

==== 尧（放勋）

帝喾之子，名放勋。

* 其仁如天，其知如神
* 就之如日，望之如云；富而不骄，贵而不舒
* 能明驯德，以亲九族；九族既睦，便章百姓；百姓昭明，合和万国
* 命羲和敬顺昊天，历象日月星辰，敬授民时
* 命羲仲宅嵎夷，寅宾出日（定春分）
* 命羲叔宅南交，敬致（定夏至）
* 命和仲宅西，饯纳日（定秋分）
* 命和叔宅朔方，在幽都（定冬至）
* 期三百六十六日，以闰月正四时
* 洪水滔天，荡荡怀山襄陵，下民其忧
* 命鲧治水，九年功不成
* 在位七十载，求能者治天下
* 四岳举虞舜
* 以二女妻舜以观其内，使九男与处以观其外
* 尧使舜入山林川泽，暴风雷雨，舜行不迷，尧以为圣
* 命舜摄行天子事
* 尧崩，百姓悲哀，如丧父母，三年四方莫举乐
* 三年丧毕，舜让辟丹朱于南河之南
* 诸侯朝觐者不之丹朱而之舜，舜曰"天也"，乃践天子位

.原文
[quote]
____
帝尧者，放勋。其仁如天，其知如神。就之如日，望之如云。富而不骄，
贵而不舒（傲慢）。黄收（黄色冠冕）纯衣，彤车乘白马。能明驯
（xùn，顺；一作"俊"）德，以亲九族。九族既睦，便章（辨明）百姓。
百姓昭明，合和万国。
____

[quote]
____
乃命羲和，敬顺昊天，数法日月星辰，敬授民时。分命羲仲，宅嵎
（yú）夷，曰旸（yáng）谷。敬道日出，便程东作。日中，星鸟，以殷
（yīn，正）中春。其民析（分散耕作），鸟兽字微（生育）。
____

[quote]
____
尧曰："嗟！四岳：朕在位七十载，汝能庸命，践朕位？"岳应曰："鄙德
忝（tiǎn，辱没）帝位。"尧曰："悉举贵戚及疏远隐匿者。"众皆言於尧
曰："有矜（鳏夫）在民间，曰虞舜。"尧曰："然，朕闻之。其何如？"
岳曰："盲者子。父顽，母嚚（yín，愚蠢），弟傲，能和以孝，烝烝
（zhēng，孝顺）治，不至奸。"尧曰："吾其试哉。"
____

[quote]
____
尧崩，百姓悲哀，如丧父母。三年，四方莫举乐，以思尧。尧知子丹朱之
不肖（xiào，贤能），不足授天下，於是乃权授舜。授舜，则天下得其利
而丹朱病；授丹朱，则天下病而丹朱得其利。尧曰"终不以天下之病而利
一人"，而卒授舜以天下。
____

==== 舜（姚重华／虞舜）

名重华，瞽叟（gǔ sǒu，盲人老者）之子。冀州之人，舜生于诸冯。

* 父顽、母嚚、弟象傲，皆欲杀舜
* 舜顺适不失子道，兄弟孝慈
* 舜耕历山，历山之人皆让畔
* 渔雷泽，雷泽上人皆让居
* 陶河滨，河滨器皆不苦窳（yǔ，粗劣）
* 一年而所居成聚，二年成邑，三年成都
* 年二十以孝闻
* 年三十尧举之
* 尧以二女妻舜，九男与处
* 瞽叟使舜上涂廪（lǐn，粮仓），从下纵火；舜以两笠自扞而下
* 又使舜穿井，舜穿井为匿空旁出；瞽叟与象下土实井，舜从匿空出
* 年五十摄行天子事
* 行天子事，巡狩四岳，班瑞于群后
* 举八恺八元，天下咸服
* 流四凶族：浑敦、穷奇、梼杌、饕餮，投诸四裔
* 殛（jí，流放）鲧于羽山
* 举禹治水，禹乃遂与益、后稷奉帝命
* 禹治水十三年，三过家门而不入
* 命契为司徒，敬敷五教
* 命皋陶作士（狱官），五刑有服
* 年五十八尧崩，年六十一代尧践帝位
* 践帝位三十九年，南巡狩，崩于苍梧之野
* 葬于江南九疑，是为零陵
* 禹避舜之子商均于阳城，诸侯皆去商均而朝禹

.原文
[quote]
____
虞舜者，名曰重华。重华父曰瞽叟，瞽叟父曰桥牛，桥牛父曰句望，
句望父曰敬康，敬康父曰穷蝉，穷蝉父曰帝颛顼，颛顼父曰昌意：
以至舜七世矣。自从穷蝉以至帝舜，皆微为庶人。
____

[quote]
____
舜父瞽叟盲，而舜母死，瞽叟更娶妻而生象，象傲。瞽叟爱後妻子，常欲
杀舜，舜避逃；及有小过，则受罪。顺事父及後母与弟，日以笃（dǔ，
诚恳）谨，匪（非）有解（懈怠）。
____

[quote]
____
舜耕历山，历山之人皆让畔（田界）；渔雷泽，雷泽上人皆让居；陶河滨，
河滨器皆不苦窳（yǔ，粗劣）。一年而所居成聚（村落），二年成邑，
三年成都。
____

[quote]
____
舜年二十以孝闻。三十而帝尧问可用者，四岳咸荐虞舜，曰可。於是尧乃
以二女妻舜以观其内，使九男与处以观其外。舜居妫（guī）汭（ruì，
水曲），内行弥（mí，更加）谨。尧二女不敢以贵骄事舜亲戚，甚有妇道。
尧九男皆益笃。
____

[quote]
____
瞽叟尚复欲杀之，使舜上涂廪（lǐn，粮仓），瞽叟从下纵火焚廪。舜乃
以两笠（lì，斗笠）自扞（hàn，保护）而下，去，得不死。後瞽叟又使舜
穿井，舜穿井为匿空（暗道）旁出。舜既入深，瞽叟与象共下土实井，舜
从匿空出，去。
____

[quote]
____
於是帝尧老，命舜摄行天子之政，以观天命。舜乃在璿（xuán，美玉）玑
玉衡，以齐七政（日月五星）。遂类（祭）于上帝，禋（yīn，祭）于六宗，
望于山川，辩（遍）于群神。
____

[quote]
____
流共工于幽陵，以变北狄；放驩兜（huān dōu）于崇山，以变南蛮；迁
三苗于三危，以变西戎；殛（jí，诛）鲧于羽山，以变东夷：四罪而天下
咸服。
____

== 夏

依据：《史记·夏本纪》

=== 禹（姒文命／大禹）

鲧之子。禹之父鲧，鲧之父帝颛顼，颛顼之父昌意，昌意之父黄帝。

* 鲧治水九年，功用不成，舜殛鲧于羽山
* 舜举鲧子禹，使续鲧之业
* 禹伤先人父鲧功之不成受诛，乃劳身焦思
* 居外十三年，过家门不敢入
* 薄衣食，致孝于鬼神；卑宫室，致费于沟淢（xù，水道）
* 陆行乘车，水行乘船，泥行乘橇（qiāo），山行乘檋（jú，登山用具）
* 左准绑，右规矩，载四时，以开九州，通九道，陂九泽，度九山
* 令益予众庶稻，可种卑湿
* 命后稷予众庶难得之食；食少，调有余相给，以均诸侯
* 禹乃行相地宜所有以贡，及山川之便利
* 声教讫于四海
* 於是帝锡禹玄圭，以告成功于天下
* 帝舜荐禹于天，十七年而帝舜崩
* 禹辞辟舜之子商均于阳城，天下诸侯皆去商均而朝禹
* 禹於是遂即天子位，南面朝天下，国号曰夏后
* 禹东巡狩，至于会稽而崩

.原文
[quote]
____
禹为人敏给克勤；其德不违，其仁可亲，其言可信；声为律，身为度，
称以出；亹亹（wěi，勤勉）穆穆，为纲为纪。
____

[quote]
____
禹伤先人父鲧功之不成受诛，乃劳身焦思，居外十三年，过家门不敢入。
薄衣食，致孝于鬼神。卑宫室，致费于沟淢（xù，水道）。陆行乘车，
水行乘船，泥行乘橇（qiāo），山行乘檋（jú，登山用具）。左准绑，
右规矩，载四时，以开九州，通九道，陂（bēi，筑堤）九泽，度九山。
____

[quote]
____
令益予众庶稀，可种卑湿。命后稷予众庶难得之食。食少，调有余相给，
以均诸侯。禹乃行相地宜所有以贡，及山川之便利。
____

[quote]
____
东渐于海，西被于流沙，朔、南暨（jì，及）：声教讫（qì，至）于四海。
於是帝锡禹玄圭，以告成功于天下。天下於是太平治。
____

=== 启

禹之子。

* 帝禹立而举皋陶荐之，且授政焉，而皋陶卒
* 禹封皋陶之后于英、六
* 禹举益，任之政
* 禹崩，以天下授益
* 三年之丧毕，益让帝禹之子启
* 诸侯皆去益而朝启，曰"吾君帝禹之子也"
* 於是启遂即天子之位，是为夏后帝启
* 有扈氏不服，启伐之，大战于甘
* 遂灭有扈氏，天下咸朝

.原文
[quote]
____
帝禹东巡狩，至于会稽而崩。以天下授益。三年之丧毕，益让帝禹之子启，
而辟居箕山之阳。禹子启贤，天下属意焉。及禹崩，虽授益，益之佐禹
日浅，天下未洽。故诸侯皆去益而朝启，曰"吾君帝禹之子也"。於是
启遂即天子之位，是为夏后帝启。
____

[quote]
____
有扈氏不服，启伐之，大战于甘。将战，作《甘誓》，乃召六卿申之。
启曰："嗟！六事之人，予誓告女（汝）：有扈氏威侮五行，怠弃三正，
天用剿绝其命。今予维共（恭）行天之罚。左不攻于左，右不攻于右，
女不共命。御非其马之政，女不共命。用命，赏于祖；不用命，僇
（lù，戮）于社，予则帑（nú，奴）僇女。"遂灭有扈氏。天下咸朝。
____

== 商

依据：《史记·殷本纪》

=== 契

商之始祖。帝喾之子，母曰简狄。

* 简狄行浴，见玄鸟堕其卵，简狄取吞之，因孕生契
* 契长而佐禹治水有功
* 帝舜乃命契曰："百姓不亲，五品不训，汝为司徒而敬敷五教，五教在宽。"
* 封于商，赐姓子氏

.原文
[quote]
____
殷契，母曰简狄，有娀（sōng）氏之女，为帝喾次妃。三人行浴，见玄鸟
堕其卵，简狄取吞之，因孕生契。契长而佐禹治水有功。帝舜乃命契曰：
"百姓不亲，五品不训，汝为司徒而敬敷五教，五教在宽。"封于商，
赐姓子氏。

=== 成汤（子履／天乙／商汤）

==== 后稷（弃）

周之始祖。帝喾元妃姜原之子。

* 姜原出野，见巨人迹，心忻然悦，欲践之，践之而身动如孕者

* 弃为儿时，屹如巨人之志
* 其游戏，好种树麻、菽，麻菽美
* 及为成人，遂好耕农，相地之宜
* 民皆法则之
* 帝尧闻之，举弃为农师，天下得其利
* 帝舜封弃於邰，号曰后稷，别姓姬氏

.原文
[quote]
____

[quote]

==== 文王（姬昌／西伯昌）
